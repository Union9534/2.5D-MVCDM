# 2.5D-MVCDM
The code of article "A Multi-View Conditioned Diffusion Framework for 3D Seismic Data Reconstruction".
# Dataset
You can find the dataset used for training, evaluation and testing on https://wiki.seg.org/wiki/Open_data.
# How to Start Training
1.Setup the Environment
2.Download the Dataset
Download the dataset from https://wiki.seg.org/wiki/Open_data.
3.Run the Training Script
python train.py
4.Run the Testing Script
python sample_3D.py
